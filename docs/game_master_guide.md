# Game master guide

## Before the meeting

- Create a dedicated private Sheet, initialise the Apps Script project and generate the host secret.
- Deploy and test the public web app URL in a signed-out window.
- Open the host dashboard and create a fresh game with the expected player cap.
- Keep the dashboard on your device. Open **Presentation view** in a second tab for Google Meet screen sharing.
- Paste the one shared player URL into the Meet chat. Players should not share their screens while their private card is visible.

## 20 minute run sheet

| Time | Host action | Group activity |
|---|---|---|
| 0–2 min | Welcome players; keep registration open. | Join with distinct names and privately read character cards. |
| 2–4 min | Start the mystery, then move to Round One. Read the opening story. | Set the scene and establish initial theories. |
| 4–8 min | Release the first evidence cards manually. | Compare the incident window and first alibis. |
| 8–12 min | Move through Round Two and release the next evidence. | Question motives, routes and witness statements. |
| 12–15 min | Move to Round Three and release the decisive evidence. | Revisit contradictions and make a case. |
| 15–17 min | Start final discussion, open voting, then close it. | Deliver short closing arguments and cast a private vote. |
| 17–20 min | Reveal the truth and explain the evidence. | Compare the accusation with the solution. |

Each phase transition is controlled by the host; the on-screen timer is a pacing aid and does not force a transition. For a shorter session, keep discussion brief and release clues in quick succession. For a longer session, allow extra time before advancing each round.

## Host checklist

1. Open the host dashboard.
2. Create the game and set the player cap.
3. Copy the shared player URL.
4. Paste it in Google Meet chat.
5. Wait for players and check the roster.
6. Start the mystery.
7. Share the separate presentation view.
8. Release evidence as the discussion develops.
9. Open and close voting.
10. Reveal the truth and walk through the timeline.

## Useful reminders

- The host solution panel is private to the authenticated host. Do not share the dashboard tab.
- Presentation view contains public information and released evidence. It never includes character cards.
- The host sees only a vote count while voting remains open. After closing, aggregate totals are available.
- A tied or empty ballot is inconclusive. Explain the actual culprit separately during the reveal.
- The host can revoke a lost player session from the roster. Ask that player to rejoin with a distinct name.
- Reset / replay clears the active game. Completed results are saved to GameHistory.
